# Production Vietnamese Learning Collection

This collection contains Vietnamese language flashcards focused on essential vocabulary for travelers and beginners.

## Decks Included

- **Vietnamese-Numbers.md**: Numbers 1-1000 with pronunciation guides
- **Vietnamese-Travel.md**: Essential travel vocabulary including greetings, food, transportation, and places

## How to Use

1. Start with numbers to build confidence with pronunciation
2. Progress to travel vocabulary for practical communication
3. Use the cloze deletion cards to practice recall and context

## Pronunciation Guide

Vietnamese pronunciation is indicated in parentheses using simplified phonetic spelling:
- **gam urn** = cảm ơn (thank you)
- **sin chow** = xin chào (hello)
- **bow nyee-ooh** = bao nhiêu (how much)

## Study Tips

- Focus on tone and pronunciation - Vietnamese is a tonal language
- Practice numbers daily as they appear everywhere
- Learn greetings first to start conversations politely
- Master essential phrases before expanding vocabulary
